--- English (handoff for another developer) ------------------------------------

1. PROJECT OVERVIEW
   - Stack: Next.js 16.x, React 19, TypeScript, Tailwind CSS v4, ESLint, Prettier.
   - AI chat: packages `ai`, `@ai-sdk/react`, `@ai-sdk/openai`.
   - Hosting: Vercel linked to GitHub (ilana283/my-next-app or AI-Driven-Development).
   - Site language: English; chat may answer in Hebrew when the user writes in Hebrew.

2. INFORMATION ARCHITECTURE (routes)
   - /                 Home — hero (name, role, tagline, profile photo, CTA links),
                       featured projects from site.projects.
   - /about            About me, Experience (Timeline), Education, Training, Skills.
   - /projects         Full project list (ProjectCard).
   - No /contact page — contact via home links and chat fallback email.

3. KEY FILES — CONTENT & SHELL
   - app/site.ts          Single source: nav, about, experience, education, training,
                          skills, projects, links, logo, profileImage, chat copy,
                          CHAT_MAX_QUESTIONS, CHAT_LIMIT_ENABLED.
   - app/layout.tsx       Fonts, metadata, ChatWidgetRoot (global floating chat).
   - app/globals.css      Tailwind v4, brand tokens, .page-glow background.
   - app/components/
       SiteShell.tsx      Header (LogoWordmark + nav), main, footer.
       Reveal.tsx         Scroll reveal (client).
       ui.tsx             Panel, SectionTitle.
       LogoWordmark.tsx   Navbar logo image.
       ProfileAvatar.tsx  Home hero photo.
       Timeline.tsx       Experience + education layout (subtitleBelowTitle option).
       SkillsSection.tsx  Skill categories (Title Case headings).
       ProjectCard.tsx    Projects page cards.

4. KEY FILES — AI CHAT
   - app/Chat.png           Assistant avatar (imported statically).
   - app/chat-avatars.ts    Exports chatAvatar for UI.
   - app/components/ChatWidget.tsx   Floating pill + avatar toggle button + panel.
   - app/components/Chat.tsx         Messages, 3-question counter, section scroll.
   - app/components/ChatAvatar.tsx   Circular avatar (sm/md/lg).
   - app/components/ChatWidgetRoot.tsx
   - app/components/chat-navigate.ts revealSiteSection + highlight after reply.
   - app/api/chat/route.ts  POST /api/chat — OpenAI or site fallback.
   - lib/chat-topics.ts     Topic detection + answerFromSiteContent (Hebrew/English).
   - lib/chat-fallback.ts   Re-exports topics.
   - lib/chat-storage.ts    sessionStorage; clear on page load (refresh).
   - lib/site-context.ts    System prompt when OpenAI is configured.
   - .env.example           OPENAI_API_KEY (optional).

5. CHAT BEHAVIOUR
   - Placeholder pill: "Ask about Ilana..." when closed; closed state button shows
     avatar image (not chat icon). Open state: close (X) on copper button.
   - limitReached + offTopicReply point to ilana.p283@gmail.com.
   - detectChatTopic scrolls/highlights relevant section (e.g. education → /about).
   - Server rejects >3 user turns per request when CHAT_LIMIT_ENABLED.

6. BRANDING & ASSETS
   - public/logo.png, public/logo-original.png — wordmark; optimize via
     npm run optimize:logo (scripts/optimize-logo-tagline.mjs).
   - public/profile.jpg — home hero.
   - app/icon.png — tab icon (hand-tuned; npm run generate:icon → preview only).

7. LOCAL DEVELOPMENT
       npm install
       npm run dev              → http://localhost:3000
       npm run lint
       npm run typecheck
       npm run format:check
       npm run check            → lint + typecheck + format:check
       npm run build
   Optional: .env.local with OPENAI_API_KEY=sk-...

8. GIT & DEPLOYMENT
   - git checkout main && git pull origin main
   - git checkout -b feature/short-description
   - commit, push, open PR, verify Vercel Preview, merge to main.
   - Do not commit .env*, .next/, merge conflict markers.

9. RECENT CHANGES (2026-05-23)
   - AI portfolio chat with site-only fallback and optional OpenAI.
   - 3 questions per visit; session cleared on full page reload.
   - Hebrew topic matching (name, work, education, skills, etc.).
   - Avatar in chat header, messages, and floating open button (Chat.png).
   - Removed separate Contact page; nav is Home / About / Projects.
   - About: Timeline education layout, Training inline title, Skills Title Case.
   - Background: .page-glow radial gradients (Ilana brand colors).
   - Logo tagline optimization script; ProfileAvatar on home.
